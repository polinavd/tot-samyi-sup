# Тот Самый Суп (БЕТА ВЕРСИЯ в процессе тестирования!!!)

## Установка

В Foundry: **Модули → Установить модуль → Manifest URL**:

```text
https://github.com/polinavd/tot-samyi-sup/releases/latest/download/module.json
```

Включите модуль в мире, затем откройте **Компендиум → Тот Самый Суп · Приключение → Импортировать приключение**.

## Требования

- **Foundry 13.351** — **dnd5e 5.3.3**.
- **Foundry 14** — **dnd5e 5.3.3** или **6.x** (для 6.x нужен Foundry 14.367+).
