# Тот Самый Суп

## Установка

В Foundry: **Модули → Установить модуль → Manifest URL**:

```text
https://github.com/polinavd/tot-samyi-sup/releases/latest/download/module.json
```

Включите модуль в мире, затем откройте **Компендиум → Тот Самый Суп · Приключение → Импортировать приключение**.

## Требования

- **Foundry 13.351** — **dnd5e 5.3.3**.
- **Foundry 14** — **dnd5e 5.3.3** или **6.x** (для 6.x нужен Foundry 14.367+).
- Обязательных дополнительных модулей нет.

**Midi-QOL необязателен.** Для него нужны **DAE**, **lib-wrapper** и **socketlib**:

| Foundry | dnd5e | Midi-QOL | DAE |
| --- | --- | --- | --- |
| 13.351 | 5.3.3 | [13.0.68](https://gitlab.com/tposney/midi-qol/-/releases/v13.0.68/downloads/module.json) | 13.x, от 13.0.23 |
| 14.368+ | 5.3.3 | [14.0.15](https://gitlab.com/tposney/midi-qol/-/releases/v14.0.15/downloads/module.json) | ветка dnd5e 5, от 14.0.18 |
| 14.368+ | 6.x | [14.6.0](https://gitlab.com/tposney/midi-qol/-/releases/v14.6.0/downloads/module.json) | ветка dnd6, от 14.6.0 |
