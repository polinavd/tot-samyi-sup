# История изменений

## 1.3.0 — 27 октября 2026

Установлены 20 согласованных токенов-заглушек из бесплатных лицензированных рисунков. Все токены — PNG 512×512 с одинаковой круглой рамкой и прозрачностью снаружи. Обновлены портреты существ, прототипы токенов, изображения размещённых NPC главной сцены и соответствующие предметы-ингредиенты. Добавлены индивидуальное авторство, ссылки на источники и тексты лицензий. В README сохранена пользовательская формулировка «Компендиум». Основная карта, состав существ и игровые правила сохранены.

## 1.2.0 — 27 октября 2026

Удалены три сгенерированные сцены кладовой и их графические файлы. Сохранена только основная сцена по пользовательской карте со стенами, светом, точками журналов и исходными токенами NPC. Панель работает на главной карте; ингредиенты расставляются вручную. Новые изображения токенов не добавлены: подборка показывается отдельно до выбора пользователя.

## 1.1.1 — 26 октября 2026

Подготовлена установка через Manifest URL: манифест содержит постоянную ссылку на последний релиз и адрес ZIP конкретной версии. README различает ссылку приключения и отдельные ссылки Midi-QOL. Игровые данные и код панели не изменены.

## 1.1.0 — 26 октября 2026

Добавлена поддержка Foundry 13.351 / dnd5e 5.3.3 с сохранением совместимости с Foundry 14 / dnd5e 5.3.3 или 6. Компендий использует формат данных 13.351 / 5.3.3 для штатного преобразования новой версией. Панель назначает токенам уровень только в Foundry 14. Идентификаторы документов сохранены. README содержит отдельные ссылки Midi-QOL и требования DAE для каждой связки, а также объяснение ошибки ActiveEffect при установке ветки 14 на Foundry 13. Полный импорт и бой в обоих движках требуют проверки в запущенном Foundry.

## 1.0.1 — 26 октября 2026

Добавлена иллюстрация обложки © [Elena Kravets](https://www.artstation.com/elenamikhailova). Автор указан в карточке приключения, на первой странице руководства ведущего, в README и в источниках. Исходное изображение включено без изменений. Игровые данные и идентификаторы документов сохранены.

## 1.0.0 — 25 октября 2026

Первая сборка приключения для Foundry VTT 14 и dnd5e 6.0.0.
